# 60秒で話す形にする

読める文章と、喋れる文章は別物。
このスキルは、**すでに書いたもの**を「耳で聞いて分かる60秒」に変える。

1本つき1ファイルで `資料/台本/YYYY-MM-DD_見出し.md` に保存する。

## 1. 素材を決める（白紙から考えさせない）

**このスキルは新しいネタを発明しない。** 素材は必ず、もうこのフォルダの中にある。

| 相手の言い方 | 使う素材 |
|---|---|
| 直前に要約・深掘りをした | その内容をそのまま使う。**聞き直さない** |
| 「今週の60秒やる」だけ | 下の**お題10問**から、このフォルダに答えがあるものを**3つだけ**選んで見せ、番号で選ばせる |
| テーマを言われた | 該当するファイル（`ログ/` `仕事/` `人物/`）を開いて材料にする |

**材料が見つからないときは、書かずに止まる。**
「◯◯について、まだ書いたものが見つかりません。先に少し話してもらえますか」と返す。
一般論で埋めない。埋めた瞬間、聞いた人に「またAIか」と思われるものが出る。

## 2. 先に読む

1. `自分/文体.md` — この人の言葉づかい（無ければ `ログ/` を2〜3日分読んで口調を拾う）
2. `自分/判断の癖.md` — 何を良しとする人か
3. 素材のファイル

## 3. 書く

```markdown
---
visibility: L2
---

# 見出し（何の話か）

## ナレーション通し

本文をここに。空行で区切る。
```

- **320〜460字**。これで60秒前後になる
- **`## ナレーション通し` の見出しを、この書き方のまま1つだけ置く**。ここから下が読み上げられる
- **空行で区切る**。1ブロックは2〜3文。ブロックの切れ目が、息継ぎの間になる
- **1文は40字まで**で必ず言い切る
- 語尾は `自分/文体.md` に従う。空のときだけ「〜なんです」「〜ですね」「〜んですよ」を暫定で当てる
- **数字と固有名詞はそのまま残す**。ぼかすと聞いた人に届かない
- 箇条書き・記号・太字・**見出しと `---` を本文に入れない**（記号がそのまま読まれる／そこで読み上げが止まる）
- 他人の実名・金額・お客さんが特定できる情報は入れない（`人物/` を素材にするときは特に）

## 4. 声に出して読んでもらう

書き終えたら、**必ず声に出して読んでもらう。** これが唯一の検品。

「言いにくかった行の番号だけ教えてください」と聞き、その行だけ直す。
直した言葉は `自分/文体.md` に1行足す（この人の言い方が1つ増える）。

## 5. 数えて見せる

保存したら、本文ではなく**この3行だけ**を報告する。

```
392字（およそ58秒）／ 言いにくい語なし ／ 実名・金額なし
資料/台本/2026-09-19_見出し.md に保存しました
```

## 音にする（やりたい人だけ・任意）

**台本ができた時点で完成。** 音は要らない。
それでも音にしたい人には、このファイルがそのまま音声に変換できる形になっていることだけ伝える。
**APIキーをこのフォルダに置かせない**（`AGENTS.md`「絶対に入れないもの」）。手順はコミュニティ側で案内する。

## お題10問（「今週の60秒やる」のときに使う）

1. 今週、AIに任せて一番ラクになったこと
2. 前は時間がかかっていたのに、今は何分で終わるようになったこと
3. 最初に詰まったところと、どうやって抜けたか
4. 自分の仕事を、知らない人に30秒で説明すると
5. お客さんが最初に相談してくるときの言葉
6. 自分が「やらない」と決めていること
7. 1年前の自分に一言だけ言うなら
8. 人に勧めたい道具を1つと、その理由
9. 今いちばん時間を取られていること
10. うまくいかなかったこと1つと、そこで分かったこと

**このフォルダに答えが書いてある問いだけを出す。** 答えの無い問いを出すと、そこで止まる。

## やらないこと

- 素材が無いのに、一般論で書き始める
- 質問を重ねて材料を集めようとする（このスキルは書くためのもの。掘るのは前の工程）
- 本文を全文そのまま画面に貼る（保存してあるので、報告は3行）
- 「まとめると」「いかがでしょうか」「ぜひ」を使う
- 台本と別に、要約版・箇条書き版を作る（**同じ話を2か所に置かない**）
- 公開先（SNS・YouTube）を勝手に決める
