# 週次点検（AIが見回って、差分だけを出す）

持ち主は毎日全部を見られない。**探すのはAIの仕事。** 出すのは差分と滞留だけ。「異常なし」は書かない。

## 1. 材料を集める（持ち主に聞く前に、自分で読む）

| 見るもの | 拾うこと |
|---|---|
| `todo.md` | 期限切れ／2週間以上動いていない／今週完了したもの／AI提案で採用待ちのまま長いもの |
| `仕事/*/カルテ.md` | `次のチェック日` が今日より前のもの／打ち手が空のもの／動く線を割っている数字 |
| `受信箱/` | 14日以上あるもの（件数と名前） |
| `ログ/` の今週分 | 出来事の中で、目標に効いたこと・止まったこと |
| `AGENTS.md` の「私について」 | 目標3つ（点検はここに照らす） |

先週の `## 週次点検` がログにあれば、そこに書いた「来週の3つ」と「予測」を読む。

## 2. 出す（10行以内。持ち主のスマホで読める長さ）

```
【今週の変化】目標に効いたこと・進んだこと（3つまで）
【止まっているもの】期限切れ T◯◯／期限切れカルテ（持ち場名）／受信箱の滞留◯件
【前回のCheck】先週こう予測した → 実際こうだった → 差分の解釈（先週の点検が無ければ「初回」）
【来週の3つ】誰が・いつまでに・何を（T番号）
【判断がいるもの】1つだけ。A / B / C で
```

網羅しない。持ち主が動けるものだけを出す。

## 3. 反映する

- 来週の3つを `todo.md` に載せる（新規は T番号。既存はそのまま）
- 期限切れのカルテは、**持ち主に数字と結果を聞いてから** `karte` の手順で更新する。聞かずに日付だけ進めない
- 気づいた提案は `todo.md` の「AI提案」に P番号で置く。無断で T にしない
- 結果を `ログ/YYYY-MM.md` に `## 週次点検 YYYY-MM-DD` として残す（次週の「前回のCheck」の材料になる）
- 何をどこに書いたかを1〜3行で報告する

## やらないこと

- 「異常なし」「順調です」を書く
- 全タスク・全カルテを列挙する
- 説教・評価
- 持ち主が答えていない数字を推測で埋める
- 来週の3つを4つ以上にする
