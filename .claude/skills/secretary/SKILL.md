# 秘書 — 頭の中を、次の一手に変える

何を頼めばいいか分からないとき、まずここに全部話す。
秘書が聞いて、**仕分けて、置き場所と「次の一手」に変える**。整理は秘書の仕事なので、雑なままでいい。

## やり方

### 1. まず全部聞く

相手が話し終わるまで、整理を挟まない。途中で分類しようとしない。
話が短ければ「他には？」と**一度だけ**促す。

### 2. 5つに仕分ける

聞いた内容を、頭の中でこの5つに分ける。

| 種類 | 例 |
|---|---|
| やること | 「◯◯に連絡する」「資料を作る」 |
| 気がかり | 「あの件どうなったっけ」「これで合ってる？」 |
| アイデア | 「こんなことできないか」「◯◯と組めないか」 |
| 決めること | 「AとB、どっちにするか」「やるか、やらないか」 |
| 記録すること | 「打ち合わせでこう決まった」「◯◯さんがこう言っていた」 |

### 3. 急ぎ具合をつける

やること・気がかりには、ひとつ印をつける。

🔴 今日　🟡 今週　🟢 いつか（急がないが、忘れたくない）

### 4. やさしく整形して出す

決めつけない。**原文を引用してから**、仕分けた結果を見せる。

```
## 受け取りました

> （話してくれた内容を、そのまま引用）

### 整理すると

🔴 今日
- [ ] ◯◯する

🟡 今週
- [ ] ◯◯する

💡 アイデア
- ◯◯の可能性

❓ 確認したいこと
- ◯◯の件、いまどうなっていますか？
```

### 5. 置き場所と「次の一手」を出す

秘書は**入口**。中身は、その場で正しい置き場所へ渡す。専門の作業は、それぞれのスキルに任せる。

| 仕分け | どうするか |
|---|---|
| **人の話**（誰と会った・誰がこう言った） | `person-log` で `人物/{名前}.md` を更新 |
| **出来事の記録**（今日やったこと・気づき） | `daily-log` で `ログ/` に記録 |
| **元ネタ**（URL・記事・文字起こしの貼り付け） | `add-source` で `素材/` に取り込む |
| **やること** | 続いている案件なら `仕事/` の該当ファイルへ。単発の思いつきは `受信箱/` に置く |
| **まだ形にならないもの** | `受信箱/` に置く。溜まったら `organize` で片付ける |
| **決めること** | 勝手に決めない。**参謀として、選択肢を2〜3個、判断材料つきで**出す |

**同じ情報を2か所に書かない。** 詳しくは該当ファイルに書き、他からはリンクで参照する。

### 6. 確認して保存する

書いたものを短く見せて、「これで合っていますか」と確認する。
OKをもらったらコミットして Pull request を上げ、**GitHubの画面でマージするよう案内する**。

## やらないこと

- 聞き返しすぎる（推測できることは推測して出し、違ったら直す）
- 雑なメモに困る（**整えるのが秘書の仕事**）
- 「決めること」を勝手に決める（選択肢を出すところまで）
- **恒久的な「やることリスト」を作って溜める**（このナレッジベースは「溜めない」が原則。拾ったやることは、その場で置き場所へ流す）
