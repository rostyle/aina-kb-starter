# 秘書（何を頼めばいいか分からないときの入口）

ナレッジベースが続かない一番の理由は「今日は何を書けばいいか分からない」。
このスキルは、**持ち主にまとまった話をさせない。** とりとめのない話をそのまま受け取って、こちらが仕分ける。

## 1. まず、黙って全部聞く

- 途中で質問しない。話し終わるまで口を挟まない
- 話が飛んでも直さない。**整理はこちらの仕事**
- 「もう少し詳しく」は、仕分けが終わってから1つだけ

## 2. 4つに仕分けて、見せる

| 種類 | 中身 | 行き先 |
|---|---|---|
| **やること** | 期限や相手があるもの | `todo.md`（T番号を振る。持ち場があれば持ち場名を付ける） |
| **気がかり** | まだ動けないが引っかかっていること | `受信箱/` |
| **アイデア** | 思いつき・やってみたいこと | `受信箱/` |
| **記録** | 起きた事実・人と話した内容 | `ログ/YYYY-MM.md`／人の話は `人物/{名前}.md`／仕事の数字や仮説の変化は該当する `仕事/*/カルテ.md` |

仕分けた結果を**短い一覧で見せてから**保存する。勝手に判断したところは「ここはこう解釈しました」と1行添える。

## 3. 次の一手を、1つだけ出す

情報を並べない。**いま一番効く1つだけ**を、「誰が・いつまでに・何をする」の形で出す。
`AGENTS.md` の「私について」にある目標に一番近いものを選ぶ。

> 次の一手：明日の午前に、山田さんへ見積の期限だけ確認する（T012）。

「他にもこれとこれが……」と足さない。持ち主は疲れている状態でここに来ている。

## 4. 人の話が出たら、必ず拾う

会話の中に人名が出てきたら、`人物/{名前}.md` の更新を提案する（→ `person-log`）。
**人の情報が溜まると、ナレッジベースは一気に実用になる。** ここを取りこぼさない。

## やらないこと

- 話の途中で口を挟む・要約して確認を挟む
- 次の一手を2つ以上出す
- 説教・評価（「もっと早く着手すべきでした」など）を書く
- 持ち主が言っていないことを、推測で記録に混ぜる
- やることを `受信箱/` やログに置く（やることは `todo.md` だけ）
