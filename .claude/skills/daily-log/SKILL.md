# 今日の記録をつける

話された内容を聞き取り、`ログ/` に整理して追記する。

## やり方

### 1. まず聞く

相手が喋り終わるまで、整理を挟まない。途中で分類しようとしない。
話が短ければ「他には？」と一度だけ促す。

### 2. 仕分ける

聞いた内容を、頭の中で3つに分ける。

| 種類 | どこへ |
|---|---|
| 出来事・やったこと・気づき | `ログ/YYYY-MM.md` に追記 |
| **人の話**（誰と会った・誰がこう言った） | `人物/{名前}.md` にも反映 → `person-log` の手順に従う |
| 仕事の情報（案件の進捗・新しい依頼） | `仕事/` の該当ファイルにも反映 |
| まだ形にならない思いつき | `受信箱/` に置く |

**同じ内容を2か所にコピーしない。** ログには事実を書き、詳細は該当ファイルへのリンクにする。

### 3. ログの書き方

`ログ/YYYY-MM.md`（月ごとに1ファイル）に、日付見出しで**上から新しい順ではなく、日付順に追記**する。

```markdown
## 2026-07-23（水）

- やったこと。事実を短く。
- 気づいたこと・感じたこと。
- 誰と何を話したか（詳しくは [[人物/山田太郎]]）
```

- **1行1事実。** 長い文章にしない
- 話されていないことを補完しない。盛らない
- 曖昧な部分は「（要確認）」と書いて残す

### 4. 保存する

書いたものを短く見せて確認をとってから、コミットして Pull request を上げる。

### 5. 気づいたら伝える（1つだけ）

記録を読んでいて気づいたことがあれば、**最後に1つだけ**短く伝える。

- 同じ悩みが3回以上出てきている
- やると言ったまま2週間動いていないことがある
- 前に決めたことと逆のことをしようとしている

言いすぎない。毎回コメントすると、記録するのが億劫になる。

## やらないこと

- 励ましや感想を長く書く（記録が読みにくくなる）
- 分類に迷って手を止める（迷ったら `受信箱/`）
