# 最初のセットアップ（私についてを埋める）

このナレッジベースの持ち主のことを、対話で聞き出して `AGENTS.md` の「私について」に記録する。

## やり方

### 1. 一度に1問だけ聞く

質問を並べて出さない。**1問ずつ聞いて、答えを受け取ってから次に進む。**
相手はAIに慣れていない可能性が高い。答えやすい順に聞く。

聞く順番：

1. お名前は？（呼ばれたい呼び方も）
2. お仕事は何をされていますか？
3. **いま追いかけている目標は？**（3つまで。「売上◯万円」「◯月までに◯◯」のように、できれば数字か期限で）
4. 今いちばん時間を取られていることは？
5. できるようになりたいこと・逆に苦手なことは？
6. 大事にしている考え方・譲れないことは？

目標が出てこない人には「今年中に変わっていたいこと」を1つだけ聞く。**空欄のままでも先に進む**（あとから足せる）。

### 2. 答えを深掘りしすぎない

1〜2回の往復で次に進む。最初から完璧を目指すと、相手が疲れて続かなくなる。
**「あとから足せます」と伝えて、軽く進める。**

### 3. 答えを書き込む

- `AGENTS.md` の「私について」を埋める（`CLAUDE.md` には書かない。あれは読み込み用の1行）
- 内容が厚くなった項目は `自分/` に独立したファイルを作る（例：`自分/プロフィール.md`、`自分/目標.md`）
- `AGENTS.md` 側は要約＋リンクにして、二重管理しない

### 4. 最後に確認して保存する

埋めた内容を短くまとめて見せ、「この理解で合っていますか」と確認する。
OKをもらったら `AGENTS.md` を保存し、**「いま、あなたのパソコンの中の AGENTS.md が書き換わりました」と伝えて、実際にファイルを開いて確認してもらう**（初回はここで「できた」を体感させるのが大事）。

### 5. 次にやることを1つだけ伝える

情報を並べない。次の一手だけ渡す：

> 明日から、1日1回だけ「今日あったことを話すので記録して」と打ってください。1週間分たまると、私の答えが変わり始めます。

## やらないこと

- 質問を箇条書きで一気に投げる（相手が固まる）
- 答えていないことを推測で埋める
- 個人情報（住所・電話番号など）を聞き出す
- `CLAUDE.md` に書く
