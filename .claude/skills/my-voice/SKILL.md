# 分身の土台を育てる（文体より先に、判断の癖）

制作物（メール・記事）から先に作らない。**土台（考え方・立ち位置・文体）を先に作る**と、「1文字も直さなくていい」文章に近づく。
口調・改行だけ真似ても「私はそう言わない」が出る。効いているのは、テーマごとに変わる無意識の立ち位置と価値判断。

## 1. 材料をもらう

- 本人が書いたもの（メール・投稿・チャット・企画書）を3〜10本。話したもの（文字起こし・音声メモ）があればなお良い
- 原文は `素材/YYYY-MM-DD_自分の文章_◯◯.md` に残す（`type: 自分の文章`、`visibility` は内容で判断。人の名前・お金が入れば L3）

## 2. 抽出して、3つのファイルに分けて書く

| 何を | どこへ | 書き方 |
|---|---|---|
| **判断の癖**：迷ったとき何を優先するか、断るときの言い方、絶対にやらないこと、テーマ別の立ち位置（教える側／一緒に悩む側／挑戦中） | `自分/判断の癖.md` | 「◯◯のときは△△を優先する」の形。実例を1つ添える |
| **文体**：書き出し・語尾・改行の癖・よく使う言い回し・使わない言葉・敬語の距離 | `自分/文体.md` | 1行1癖。「〜する」で書く。**NGリスト**（言わない言葉）を必ず持つ |
| **そのまま使える言い回し** | `自分/発話サンプル.md` | **原文ママ**。冒頭に【逐語】と明記し、場面（誰に・どんな時）を1行添える |

- 【逐語】（原文ママ）と【要約】（こちらで編集した引用）を混ぜない
- 本人が言っていないことを癖として書かない。根拠になった素材へのリンクを付ける
- 既存の `自分/文体.md` があれば追記する。同じ癖を2度書かない

## 3. 確かめる（書いたら、その場で試す）

持ち主にこう打ってもらう：

> 「私について今わかっていることだけで、◯◯（メール／投稿）を書いて。そのあと、書くのに足りなかった情報を教えて」

出てきた**「足りなかった情報」が、次に埋める場所。** 当てずっぽうで足さない。
持ち主から「私はそう言わない」が出たら、その場で `自分/文体.md` の NG リストに1行足す。

## 4. 制作するときの決まり

「書いて」「作って」と言われたら、書く前に `自分/判断の癖.md` → `自分/文体.md` → `自分/発話サンプル.md` の順に読む。
書いたあと、NG リストで自己チェックしてから出す。

## やらないこと

- 口調だけを真似る（判断の癖の抽出を飛ばす）
- 一度に完璧なプロファイルを作ろうとする（3本の素材から始めて、都度足す）
- 人の発言を本人の癖として混ぜる（文字起こしは話者を確認する）
