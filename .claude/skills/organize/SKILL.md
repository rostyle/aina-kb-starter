# 片付ける・棚卸しする

ナレッジベースが死ぬ原因は、情報が少ないことではなく**散らかって信用できなくなること**。定期的に整える。

## 週1回：受信箱を空にする（5分）

### 1. `受信箱/` の中身を全部読む

### 2. 1件ずつ、4つのどれかに決める

| 判定 | 行き先 |
|---|---|
| 使える情報 | 適切なフォルダへ移す（`AGENTS.md` の KB地図に従う）。やることなら `todo.md` に T番号 |
| **既にある情報** | 既存ファイルに**統合**して、受信箱の方を消す |
| もう要らない | 消す |
| まだ決められない | 残す。**ただし3週間残り続けたものは消す**（判断できないものは、たいてい要らない） |

### 3. 迷ったら本人に聞く

判断がつかないものは、**まとめて1回だけ**聞く。1件ずつ確認を取らない（面倒になって続かなくなる）。

### 4. 終わったら報告する

「受信箱 12件 → 0件。◯◯を仕事/へ、△△を人物/へ、5件を削除しました」と3行で。

## 月1回：棚卸し（10分）

### 1. 終わったものを archive へ

- 完了した持ち場（`仕事/{持ち場}/` をフォルダごと `仕事/archive/` へ）、古くなった資料（`資料/archive/`）
- **消さずに `archive/` サブフォルダへ移す**
- 人物ファイルは**動かさない**。`status: archive` に変えるだけ
- `todo.md` の「完了（直近）」を、その月の `ログ/YYYY-MM.md` 末尾「## 完了したタスク」へ移す

### 2. 重複を潰す

- 同じことが2か所に書かれていないか探す
- 見つけたら**片方を真実源に決めて、もう片方はリンクに置き換える**
- **人の情報が `人物/` 以外に書かれていたら、必ず `人物/` へ寄せる。** やることが `todo.md` 以外にあれば `todo.md` へ寄せる

### 3. 古い情報に印をつける

事実と違うかもしれない記述には、消さずに追記する：

> （2026-07-23 時点では未確認）

打ち手が空のまま2回の点検をまたいだカルテは `稼働: 休眠` にする（動いていないものを動いているように見せない）。

### 4. 気づいたことを3つだけ報告する

- 放置されているもの（例：受信箱に3週間残っている件、採用待ちのまま1か月の P番号）
- 書きかけで止まっているファイル
- **記録から見える傾向**（例：同じ相手の名前が今月8回出ている＝関係が濃くなっている）

長い分析はしない。**3つまで。** `AGENTS.md` の直しが要りそうなら `tune-kb` を提案する。

## やらないこと

- 本人に聞かずに `人物/` や `自分/` の中身を消す
- archive に移すべきものを削除する
- 1件ずつ確認を求める
