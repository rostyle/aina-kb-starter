# 人物

**人の情報は、ここにだけ置きます。** 顧客・同僚・取引先・仲間・友人。

ここが埋まると、ナレッジベースは一気に実用的になります。
「明日◯◯さんと会うので、前回何を話したか教えて」が通じるようになります。

## ルール

- ファイルは `{名前}.md` で**フラットに**置く（顧客／同僚などのフォルダを作らない）
- 役割・状態は**フロントマターのタグ**で管理する。関係が変わってもファイルは動かさない
- **他の場所に人のプロフィールを作らない。** 他からはリンクで参照する

```yaml
---
name: 山田 太郎
relation: [顧客]     # 顧客 / 同僚 / 取引先 / 仲間 / 友人 / 家族 / 見込み
status: active       # active / watching / archive
met: 2026-07-23
---
```

## 書く人・書かない人

| 書く | 書かない |
|---|---|
| ちゃんと話したことがある人 | 名刺交換しただけの人 |
| これから継続的に関わる人 | 一度きりの問い合わせ |

**迷ったら書かない。** 増やしすぎると手入れが追いつかず、全部が古くなります。

## 何を書くか

**「調べれば分かること」ではなく「接した自分にしか分からないこと」。**

- ○ 結論から話すと機嫌がいい／値段の話を先にすると引く／前回「来期に検討」と言っていた
- ✕ 会社の設立年／公開されている経歴

## 更新のしかた

人と話したあと、AIにこう頼む：

```
◯◯さんと話した内容を伝えるので、人物ファイルを更新して。
```

## 注意

**そのまま本人に見られても困らない書き方**にしてください。悪口は書かない。
住所・電話番号・家族構成などの個人情報も書かない。
