# ログ

**日々の記録。** 月ごとに1ファイル（`2026-09.md` のように）。

## 書きかた

自分で書かない。AIに話す：

```
今日あったことを話すので、ログに整理して保存して。
```

思いつくまま喋れば、AIが日付ごとに整理して追記します。
人の話は `人物/` へ、やることは `todo.md` へ、仕事の数字や仮説の変化は該当する `仕事/*/カルテ.md` へ、AIが同時に振り分けます。ログには事実を短く残し、詳細はリンクにします。

## この中に溜まっていくもの

- 日付ごとの出来事・やったこと・気づき
- `## 週次点検 YYYY-MM-DD` — 週1回の点検結果（`weekly-review`）
- `## 完了したタスク` — 月1回の棚卸しで `todo.md` から移した完了分

## なぜ効くのか

ログが溜まると、AIが**あなたの状況・文脈・調子を踏まえて**答えられるようになります。
1週間分で「知っている人」に、1か月分で「わかっている相棒」になります。
