# 仕事

**今やっている仕事の情報。** ここが埋まると、AIが実務の相談相手になります。

## 置くもの（例）

- `いまの案件.md` — 進行中のもの一覧（終わったら `仕事/archive/` へ）
- `よくやる作業.md` — 繰り返している手順。ここに書くとAIに任せられるようになる
- `困っていること.md` — 時間を取られている作業。自動化の候補リストになる

## 人の情報は、ここに書かない

顧客・同僚・取引先のプロフィールは **`人物/` に集約**します。
ここからはリンクで参照してください。

```markdown
- ○○社の件（担当: [山田太郎](../人物/山田太郎.md)）
```

同じ人の情報が2か所にあると、必ず古い方が残って事故ります。

## ヒント

**「よくやる作業」を書き溜めるのが、いちばん効きます。**
3回以上やった作業を書いておくと、AIに「これやっといて」で渡せるようになります。
さらに繰り返すようなら、`.claude/skills/` に自分専用の手順書として置いておくと、毎回説明しなくて済みます。
