# 資料

**自分が作ったもの・まとめたものを置く場所。**

- 企画書、提案書、記事の下書き、調べてまとめたもの、学びの蓄積

元ネタ（記事の全文・文字起こし）は `素材/` へ。**混ぜないでください。**

## 置きかたの例

```
資料/学び_マーケティング.md      テーマごとに蓄積していく
資料/提案_○○社_2026-07.md       単発の成果物
資料/archive/                    終わったもの
```

## コツ：テーマごとに1ファイルで育てる

新しく学ぶたびに新規ファイルを作ると、すぐ散らかります。
**同じテーマは1ファイルに追記して育てる**ほうが、あとで効きます。

```
「マーケティングの学びに追記しておいて」
```

## 終わったら

完了した提案書や古くなった資料は、消さずに `資料/archive/` へ移します。
**現役のものだけが見えている状態**を保ってください。
