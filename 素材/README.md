# 素材

**元ネタを、加工せずそのまま置く場所。**

- 記事の全文、動画の文字起こし、打ち合わせの生ログ、講座のメモ

## なぜ原文を残すのか

要約だけ残すと、あとで「本当にそう言っていたか」を確認できなくなります。
**元を確認できることが、信頼できるナレッジベースの条件です。**

まとめたものは `資料/` へ。**ここ（元ネタ）と混ぜないでください。**

## ファイルの形

`YYYY-MM-DD_{何の素材か}.md` として、冒頭に出どころを書く。

```markdown
---
source: https://example.com/article
type: 記事          # 記事 / 動画 / 打ち合わせ / 講座 / 本
date: 2026-07-23
---

（ここに原文）
```

## 入れかた

```
これを素材として取り込んで、要点をまとめておいて。
（そのあとURLやテキストを貼る）
```

## 注意

- **出どころ不明のまま入れない**（必ず source を書く）
- 有料コンテンツや他人の著作物を**丸ごとコピーして置かない**。要点と出どころに留める
- 打ち合わせの録音・文字起こしは、**参加者に配慮した内容だけ**残す
