# 自分（分身の土台）

**自分自身のことを書く場所。** AIが「あなたとして」考え、「あなたの言葉で」書くための土台になります。

（他人のことは `人物/` へ。ここは自分専用です）

## 置くもの

| ファイル | 中身 | 育てかた |
|---|---|---|
| `プロフィール.md` | 経歴・強みと弱み・価値観（`AGENTS.md` の「私について」が厚くなったら、ここへ移す） | `setup-me` のあと、話すたびに追記 |
| `目標.md` | 1年後 / 3年後にどうなっていたいか。いま追いかけている3つの目標の背景 | 変わったときに書き換える |
| `文体.md` | **自分の言葉づかいの癖**（書き出し・語尾・改行・よく使う言い回し・使わない言葉） | `my-voice` |
| `判断の癖.md` | 迷ったときに何を優先するか・断り方・絶対にやらないこと | `my-voice` |
| `発話サンプル.md` | そのまま使える自分の言い回し（**原文ママ**。要約と混ぜない） | `my-voice` |

## なぜ「文体」より先に「判断の癖」か

口調だけ真似させても「私はそう言わない」が出ます。効くのは、**テーマごとに立ち位置が変わる**（この話題では教える側、この話題では一緒に悩む側）といった、無意識の判断です。
先に判断の癖を言葉にし、そのうえで文体を重ねると、「1文字も直さなくていい」文章に近づきます。

## 増やしかた

無理に一度で埋めない。日々の記録が溜まってきたら、AIにこう頼む：

```
ログ/ を読んで、私について新しくわかったことを 自分/ に反映して。
```

自分が書いた文章（メール・投稿・チャット）をいくつか貼って、こう頼む：

```
この文章から、私の書き方の癖と判断の癖を抜き出して 自分/ にまとめて。
```

AIに書かせた文章が「自分っぽくない」と感じたら、その場で「私はそう言わない」と伝える。それが `文体.md` の NG リストになります。
