# 自分

**自分自身のことを書く場所。** AIが「あなたとして」考えるための土台になります。

（他人のことは `人物/` へ。ここは自分専用です）

## 置くもの（例）

- `経歴.md` — これまでやってきたこと
- `強みと弱み.md` — 得意 / 苦手
- `価値観.md` — 大事にしていること、譲れないこと
- `目標.md` — 1年後 / 3年後にどうなっていたいか
- `文体.md` — **自分の言葉づかいの癖**（AIに真似させるため。ここが効きます）

## 増やしかた

無理に一度で埋めない。日々の記録が溜まってきたら、AIにこう頼む：

```
ログ/ を読んで、私について新しくわかったことを 自分/ に反映して。
```

## 文体.md の作り方

自分が書いた文章（メール・投稿・チャット）をいくつか貼って、こう頼む：

```
この文章から、私の書き方の癖を抜き出して 自分/文体.md にまとめて。
```

これがあると、AIに書かせた文章の「自分っぽくなさ」が一段減ります。
