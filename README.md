# 自分のナレッジベース（AiNA式）

AIが「あなた」を理解して、あなたの代わりに考え・作業するための場所です。
**入れるのはアプリ1つだけ。コードは1行も書きません。**

めちゃくちゃ分かりやすく言うと、これは**AIの脳みそ**です。
会社で仕事を任せやすいのは、長年いっしょにいる同僚です。経験を共有しているから「あの時のあの感じで」が通じる。
それをAIで作ります。人間は忘れないと頭がパンクしますが、AIは貯めていけます。**なんでもいいから、とにかく入れる。** それだけで答えが変わります。

> **最初に全部を理解しなくて大丈夫。** まずは下の「はじめかた」だけやってください。
> 残り（持ち場・人物・スキル）は、必要になったときに読めば十分です。

---

## はじめかた（15分）

### ① Claude のデスクトップアプリを入れる

[claude.ai](https://claude.ai) を開いて、**デスクトップアプリ**をダウンロード（Windows は `.exe`／Mac は `.dmg`）。
インストールして起動し、**Claude の有料プランのアカウントでログイン**します。

> インストール時に「開発元を確認できません」と出たら、Mac は**「システム設定 → プライバシーとセキュリティ」**で許可、
> Windows は**「詳細情報 → 実行」**で進めます。

### ② このフォルダを `my-kb` にして、デスクトップに置く

いま読んでいるこのフォルダの名前を **`my-kb`** に変えて、**デスクトップ**に置いてください。

> ZIP で受け取った場合は、**先に解凍**してから。解凍後に同じ名前のフォルダが二重になっていることがあります。
> その場合は、**`AGENTS.md` が直接見えているほう**を `my-kb` にしてください。

### ③ アプリでそのフォルダを開く

デスクトップアプリの **「Code」** を開いて、`my-kb` フォルダを選ぶだけ。
これで「AIが、このフォルダの中で作業できる状態」になりました。

### ④ 最初の1回を話しかける

入力欄にこう打ってください。

```
AGENTS.md の「私について」が空欄なので、私に1つずつ質問しながら埋めてください。
```

AIが質問してきます。答えるだけで、あなたの説明書ができあがります。
**保存はAIがやります。** あなたが「保存」を押す必要はありません。書いたものは、そのままこのフォルダの中に残ります。

終わったら `AGENTS.md` を開いて、「私について」が埋まっているのを自分の目で見てください。
**いま、AIがあなたのパソコンの中のファイルを書き換えました。これがあなたの財産の1個目です。**

> ⚠️ **このフォルダは消さないでください。** ここがあなたの財産になっていきます。
> バックアップ（GitHub）の取り方は、慣れてきた頃に別途扱います。**今は要りません。**

## 次の日から（1日1分）

思いついたこと・あった出来事を、そのまま話しかけるだけです。

```
今日あったことを話すので、適切な場所に整理して保存してください。
（そのあと、思いつくまま喋る）
```

置き場所はAIが判断します。あなたが迷う必要はありません。

### 最初の7日（1日1つずつ。これで全部の仕組みを1回ずつ通ります）

| 日 | 打つこと | 何が育つか |
|---|---|---|
| 1日目 | 「私について質問しながら埋めて」 | `AGENTS.md` の「私について」 |
| 2日目 | 「今日あったことを話すので記録して」 | `ログ/` |
| 3日目 | 「よく会う人を3人紹介するので、人物ファイルを作って」 | `人物/` |
| 4日目 | 「いま抱えている仕事を1つ話すので、持ち場を立てて」 | `仕事/{持ち場}/` の README と カルテ |
| 5日目 | 「この記事（or この打ち合わせのメモ）を取り込んで」 | `素材/` と `資料/` |
| 6日目 | 「私が書いたメールを3通貼るので、文体を覚えて」 | `自分/文体.md` |
| 7日目 | 「週次レビューして」 | `todo.md` と、止まっているものの点検 |

7日目に、素のチャット（何も読んでいないAI）と同じ質問をして、答えを比べてみてください。**その差が、ナレッジベースの正体です。**

## スマホと PC について（先に言っておきます）

このフォルダは**あなたの PC の中**にあります。ChatGPT のように、スマホから自動で同じものが見えるわけではありません。
スマホからも使いたくなったら、GitHub にバックアップを置く手順（慣れてきた頃に扱います）を入れると、PC とスマホで同じナレッジベースを開けるようになります。**最初の1〜2週間は PC だけで十分です。**

## 慣れてきたら使うもの

最初から入っています。**日本語で頼めば、AIが勝手に使います**（コマンドを覚える必要はありません）。

| やりたいこと | こう言えばいい | 中で動くもの |
|---|---|---|
| 何を頼めばいいか分からない | 「秘書、ちょっと聞いて」（そのあと思いつくまま話す） | `secretary` |
| 今日の記録 | 「今日あったことを記録して」 | `daily-log` |
| 記事・動画・議事録を取り込む | 「これ入れといて」（URL やテキストを貼る） | `add-source` |

| 仕事を1つ、AIと一緒に回す | 「◯◯の持ち場を立てて」「カルテを更新して」 | `karte` |
| 週1回の点検 | 「週次レビューして」 | `weekly-review` |
| 散らかりを片付ける | 「受信箱を片付けて」「月次の棚卸しして」 | `organize` |

手順の中身は `.claude/skills/` に入っています。**自分で書き換えて、自分専用に育てられます。**

## フォルダの意味

```
AGENTS.md   AIへの指示書。ここが一番大事（Claude Code も Codex もこれを読む）
CLAUDE.md   AGENTS.md を読み込むだけの1行。触らない
todo.md     やることの一覧。ここだけ

受信箱/     とりあえず何でも放り込む。溜めずに片付ける
自分/       自分のこと（プロフィール・目標・文体・判断の癖）＝ 分身の土台
人物/       ★人のこと（顧客・同僚・取引先・仲間）。人の情報はここだけ
仕事/       持ち場ごとに README（役割）と カルテ（今の状態）
ログ/       日々の記録（月ごと1ファイル）
素材/       元ネタ（記事の全文・文字起こし・打ち合わせの生ログ）
資料/       自分が作ったもの・まとめたもの
共有/       仲間や会社と共有するプロジェクトを置く場所（あとで使う）
```

**最初は `受信箱/` と `ログ/` だけ使えば十分です。** 残りは必要になったら埋まっていきます。
各フォルダの中に README があるので、使うときに読んでください。

## この型は、会社を AI で回している形と同じです

このテンプレは、株式会社AiNA が自社の経営で実際に使っているナレッジベースを、個人の大きさに縮めたものです。中身は同じ4つの型です。

1. **AIへの指示書は1本**（`AGENTS.md`）。ツールが変わっても同じものを読む
2. **役割（README）と今の状態（カルテ）を分ける**。だからAIが、次に開いたときも前回の続きを覚えている
3. **タスクは1本**（`todo.md`）。AIが見つけた提案は、あなたがOKするまで別枠に置く
4. **AIが聞かずにやっていい範囲を、最初に書く**。だから毎回の「やっていいですか」が消える

仕事が増えたら `仕事/` の中に持ち場が増えるだけで、フォルダの形は変わりません。会社で使うなら、持ち場が部署になります。

## Claude Code 以外で使う場合（Codex など）

**同じフォルダが、そのまま使えます。** ルールは `AGENTS.md` に書いてあり、Codex はそれを直接読みます。
手順（スキル）を自動で読み込まないツールの場合は、最初にこう言ってください。

```
AGENTS.md を読んでから作業して。手順書は .claude/skills/ にあります。
```

ツールは**どちらか1つに決めてください**（両方に課金しない）。

---

## 大事なルール

1. **同じ情報を2か所に書かない** — 迷ったらAIに「どこに書くべき？」と聞く
2. **人の情報は `人物/` だけ、タスクは `todo.md` だけ**
3. **元ネタと、まとめを分ける** — `素材/` と `資料/` を混ぜない
4. **受信箱を溜めない** — 週に1回は片付ける
5. **入れてはいけないものを入れない** — パスワード・APIキー・仕事の機密の原本・他人の個人情報
6. **完璧を目指さない** — 雑でいい。書き続けたほうが勝ち

## このテンプレは進化します

あなたがコピーしたものは、**コピーした時点であなた専用**になります。元が新しくなっても、勝手に書き換わることはありません。

更新があったときはコミュニティでお知らせします。取り込みたければ、お知らせの文章をそのままAIに貼って「これを私のナレッジベースにも反映して」と頼むだけ。
**取り込まなくても、今のままで動きます。**

テンプレの版：**v2（2026-09-19）**。v1 からの変更＝指示書を `AGENTS.md` に一本化／`仕事/` を README＋カルテの持ち場形式に／`todo.md`・`共有/` を追加／スキルに `karte`・`weekly-review`・`my-voice` を追加。
