# 自分のナレッジベース

AIが「あなた」を理解して、あなたの代わりに考え・作業するための場所です。
インストールは何も要りません。**ブラウザだけで動きます。**

> **最初に全部を理解しなくて大丈夫。** まずは下の「はじめかた」だけやってください。
> 残り（スキル・人物・素材）は、必要になったときに読めば十分です。

---

## はじめかた（15分）

### ① このテンプレを自分のものにする
このページ右上の緑のボタン **「Use this template」→「Create a new repository」** を押す。

- Repository name: `my-kb`（好きな名前でOK）
- **Private を必ず選ぶ** ← ここ重要。自分のことを書く場所なので非公開にします
- 「Create repository」

### ② Claude Codeにつなぐ
[claude.ai/code](https://claude.ai/code) を開く（Claude Proのアカウントでログイン）。

- 初回だけ GitHub との接続を聞かれるので許可する
- リポジトリの一覧から、①で作った `my-kb` を選ぶ

これで準備完了です。パソコンの設定は一切ありません。スマホのブラウザでも同じことができます。

### ③ 最初の1回を話しかける
入力欄にこう打ってください。

```
CLAUDE.md の「私について」が空欄なので、私に質問しながら埋めてください。
1つずつ聞いてください。
```

AIが質問してきます。答えるだけで、あなたの説明書ができあがります。

### ④ できたものを取り込む（＝はじめてのマージ）
作業が終わると、GitHubに「Pull request」というものが作られます。

- GitHub の `my-kb` を開く → 上のタブの **Pull requests**
- 出ているものを開いて、緑の **「Merge pull request」** → **「Confirm merge」**

これで、あなたのナレッジベースに情報が保存されました。**ここまでで完了です。**

## 次の日から（1日1分）

思いついたこと・あった出来事を、そのまま話しかけるだけです。

```
今日あったことを話すので、適切な場所に整理して保存してください。
（そのあと、思いつくまま喋る）
```

置き場所はAIが判断します。あなたが迷う必要はありません。
**まず7日続けてみてください。** AIの答えが変わり始めます。

## 慣れてきたら使うもの

最初から入っています。**日本語で頼めば、AIが勝手に使います**（コマンドを覚える必要はありません）。

| やりたいこと | こう言えばいい | 中で動くもの |
|---|---|---|
| 記事・動画・議事録を取り込む | 「これ入れといて」（URLやテキストを貼る） | `add-source` |
| 人と会った記録を残す | 「◯◯さんと打ち合わせした内容を伝えるので更新して」 | `person-log` |
| 散らかりを片付ける | 「受信箱を片付けて」 | `organize` |
| 今日の記録 | 「今日あったことを記録して」 | `daily-log` |
| 最初のセットアップ | 「私について質問しながら埋めて」 | `setup-me` |

手順の中身は `.claude/skills/` に入っています。**自分で書き換えて、自分専用に育てられます。**

## フォルダの意味

```
CLAUDE.md   AIへの指示書。ここが一番大事
AGENTS.md   Claude Code以外のAI（Codexなど）で使うとき用

受信箱/     とりあえず何でも放り込む。溜めずに片付ける
自分/       自分のこと（経歴・強み・価値観・目標・文体）
人物/       ★人のこと（顧客・同僚・取引先・仲間）。人の情報はここだけ
仕事/       案件・進行中のもの・よくやる作業
ログ/       日々の記録（月ごと1ファイル）
資料/       自分が作ったもの・まとめたもの
素材/       元ネタ（記事の全文・文字起こし・打ち合わせの生ログ）
```

**最初は `受信箱/` と `ログ/` だけ使えば十分です。** 残りは必要になったら埋まっていきます。

各フォルダの中に README があるので、使うときに読んでください。

## Claude Code 以外で使う場合（Codex など）

**同じリポジトリが、そのまま使えます。**

ルールは `CLAUDE.md` に書いてあり、`AGENTS.md` がそこへ案内します。
Codexなどで開いた場合は、最初にこう言ってください。

```
AGENTS.md と CLAUDE.md を読んでから作業して。
```

手順（スキル）を自動で読み込まないツールの場合は、`.claude/skills/` の該当ファイルを開いてもらえば、同じことができます。
**ルールを変えるときは `CLAUDE.md` だけを直してください**（同じルールを2か所で管理しないため）。

---

## 大事なルール

1. **同じ情報を2か所に書かない** — 迷ったらAIに「どこに書くべき？」と聞く
2. **人の情報は `人物/` だけ** — 他の場所にプロフィールを作らない
3. **元ネタと、まとめを分ける** — `素材/` と `資料/` を混ぜない
4. **受信箱を溜めない** — 週に1回は片付ける
5. **入れてはいけないものを入れない** — パスワード・APIキー・仕事の機密・他人の個人情報
6. **完璧を目指さない** — 雑でいい。書き続けたほうが勝ち

## このテンプレは進化します

あなたがコピーしたものは、**コピーした時点であなた専用**になります。元が新しくなっても、勝手に書き換わることはありません。

更新があったときはコミュニティでお知らせします。取り込みたければ、お知らせの文章をそのままAIに貼って「これを私のナレッジベースにも反映して」と頼むだけ。
**取り込まなくても、今のままで動きます。**
