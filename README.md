# 自分のナレッジベース

AIが「あなた」を理解して、あなたの代わりに考え・作業するための場所です。
インストールは何も要りません。**ブラウザだけで動きます。**

---

## はじめかた（15分）

### ① このテンプレを自分のものにする
このページ右上の緑のボタン **「Use this template」→「Create a new repository」** を押す。

- Repository name: `my-kb`（好きな名前でOK）
- **Private を必ず選ぶ** ← ここ重要。自分のことを書く場所なので非公開にします
- 「Create repository」

### ② Claude Codeにつなぐ
[claude.ai/code](https://claude.ai/code) を開く（Claude Proのアカウントでログイン）。

- 初回だけ GitHub との接続を聞かれるので許可する
- リポジトリの一覧から、①で作った `my-kb` を選ぶ

これで準備完了です。パソコンの設定は一切ありません。スマホのブラウザでも同じことができます。

### ③ 最初の1回を話しかける
入力欄にこう打ってください。

```
CLAUDE.md の「私について」が空欄なので、私に質問しながら埋めてください。
1つずつ聞いてください。
```

AIが質問してきます。答えるだけで、あなたの説明書ができあがります。

### ④ できたものを取り込む（＝はじめてのマージ）
作業が終わると、GitHubに「Pull request」というものが作られます。

- GitHub の `my-kb` を開く → 上のタブの **Pull requests**
- 出ているものを開いて、緑の **「Merge pull request」** → **「Confirm merge」**

これで、あなたのナレッジベースに情報が保存されました。**ここまでで課題クリアです。**

---

## 次の日から

思いついたこと・あった出来事を、そのまま話しかけるだけです。

```
今日あったことを話すので、適切な場所に整理して保存してください。
（そのあと、思いつくまま喋る）
```

置き場所はAIが判断します。あなたが迷う必要はありません。

## 使えるひとこと集（コピペ可）

| やりたいこと | 打つ言葉 |
|---|---|
| 今日の記録をつける | `今日あったことを話すので整理して保存して` |
| 頭の中を吐き出す | `思いついたことを言うので、受信箱に入れて整理して` |
| 仕事の情報を足す | `今やっている仕事について話すので、仕事/ にまとめて` |
| 溜まったものを片付ける | `受信箱/ を見て、中身を正しい場所に振り分けて` |
| 自分を思い出させる | `私について今わかっていることを教えて` |
| 相談する | `私の状況を踏まえて、◯◯についてどうすべきか意見をください` |
| 書いてもらう | `私の言葉づかいで、◯◯向けの文章を書いて` |

## フォルダの意味

```
受信箱/   とりあえず何でも放り込む場所。溜めずに片付ける
自分/     自分のこと（経歴・強み・価値観・目標）
仕事/     仕事のこと（案件・顧客・進行中のもの）
ログ/     日々の記録
CLAUDE.md AIへの指示書。ここが一番大事
```

---

## 大事なルール

1. **同じ情報を2か所に書かない** — 迷ったらAIに「どこに書くべき？」と聞く
2. **受信箱を溜めない** — 週に1回は片付ける
3. **入れてはいけないものを入れない** — パスワード・APIキー・他人の個人情報・会社の機密
4. **完璧を目指さない** — 雑でいい。書き続けたほうが勝ち
